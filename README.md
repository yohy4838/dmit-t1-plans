## T1 到底是什么线路，官网为什么搜不到 Lite 了

T1 全称 Tier 1，是 DMIT 三条产品线里最便宜的一档，走国际 BGP 路由，接入 NTT、PCCW、Cogent、Telstra 这类一级骨干，不做中国大陆的专项优化。

| 产品线 | 线路做法 | 大陆优化 | 洛杉矶入门价 |
| --- | --- | --- | --- |
| Premium（Pro） | 三网 CN2 GIA 双向 | 有，最强也最贵 | Pro TINY 月付 $9.99 |
| Eyeball（EB） | 电信 CN2/9929，联通移动 CMIN2 | 有，中等 | EB TINY 月付 $9.99 |
| Tier 1（T1） | 国际 BGP | 无 | T1 WEE $36.9/年 |

搜"dmit lite"的人注意：原来的 Lite 系列就是现在的 T1，改名之后线路定位没变，官网已经搜不到 Lite 这个词。香港 T1（前 HKG.Lite）的入门款仍是 $6.90/月的 TINY，$36.90/年的 WEE 也在架。

三档的价差很实在。香港这边，T1 的月付入门是 $6.90，EB 是 $29.90，Pro 是 $39.90。多出来的钱买的是中国大陆方向的路由质量，不是 CPU 和硬盘。你不需要这条路由，多花的就是冤枉钱。

## 香港 T1 的真实线路表现：移动能看，电信别直连

有评测给出的实测是：移动经 CMI 直连香港 NTT，延迟压在 50ms 出头；联通去程绕日本 NTT，回程比电信好；电信可能绕新加坡再进香港，延迟普遍超过 200ms，丢包率也比另外两家高。同一条 T1 线路，三家运营商能差出四倍延迟。

这组数字只属于香港。洛杉矶 T1 同样不做大陆优化，但没有可引用的分运营商实测数据，把香港的 50ms 直接套到美西是不成立的，中间多了一整段跨太平洋。

所以 T1 的正确用法，是把它当成一台有当地原生 IP 的落地机，前端用广移、IPLC 之类的方案自己做中转；香港 T1 能解锁 Netflix 港区，靠的就是香港原生 IP。反过来，如果你的用法是从国内直接连上去，T1 的路由质量就是你能拿到的全部，没有补救空间。

## 谁不该买 T1，该买什么

T1 适合这四种情况：

1. 自建落地节点，自己在前端做中转优化
2. 面向海外用户的网站或服务，访客本来就不在大陆
3. 开发环境、跑脚本、CI/CD 这类对线路不敏感的场景
4. 想低成本试一次 DMIT，再决定要不要上 Pro

第四种站得住脚，原因在退款条款：3 天内可以无理由全额退款，只要流量使用不超过 30GB。花 $36.9 试一台机器，比看十篇评测更直接。

不适合的只有两种：每天晚高峰要稳定访问国内，以及代理直连、对延迟敏感。这两种需求去看 Pro 或 EB，香港 EB TINYv2 是 $29.90/月、香港 Pro TINY 是 $39.90/月、洛杉矶 Pro TINY 是 $9.99/月，差距不在配置上，差在回国的路由。

如果纯粹只是要一个香港 IP 做落地或配中转，用不着上 Pro，T1 TINY 月付 $6.90 就够，$36.90/年的 WEE 更省。

## 三个只在条款里写着的成本：退款、IP、超量限速

这一节的内容基本不在套餐页上，但都会影响你实际用起来顺不顺。

**退款。** 3 天内无理由全额退款，条件是流量使用不超过 30GB；超过 3 天，30 天内可以按剩余价值退款。想试线路，把测试压缩在前三天做完。

**IP 政策。** 官方文档写明，T1 系列分配的 IP 不保证首次连接在敏感地区可用，Pro 和 EB 则保证首次全球连通，不通可以开工单处理。这就带出一个很多人买完才发现的问题：IP 是系统随机分配的，不能指定段或具体地址，也不能保证能访问某个特定网站或流媒体。

换 IP 的规则分两档。免费换只对 Pro 和 EB 开放，要同时满足购买满 7 天、距上次更换至少 15 天、ICMP 和全部 TCP 端口被封、剩余有效期至少 7 天。付费换是 $5 一次，需要购买满 24 小时、距上次更换至少 3 天、剩余有效期至少 3 天。还有一条容易被忽略：如果 IP 在开通时就已经被封，直接开工单可以免费换。

有第三方整理提到，结账时可以加 $1 勾选 "Guarantee+"，把"IP 全球可用"这件事保下来；没勾的话后续换 IP 就是上面那 $5。这个选项在不同时期的页面上出现过也消失过，下单时自己在结账页确认一眼，$1 换一次省心是值的。

**超量限速。** 流量用完不会停机，只限速。这一条对新用户最友好，月底不用提心吊胆。但限速档位三档产品差得很远：T1 超量后还有 50Mbps 到 1000Mbps 的带宽（东京 WEE 是 50Mbps，洛杉矶 WEE 是 100Mbps），跑大部分业务都还能跑；Pro 和 EB 的入门款超量后直接降到 4Mbps，那更像兜底而不是能用。买 T1 的人常常忽略这一点，其实它比线路本身更影响长期体验。
